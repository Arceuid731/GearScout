# GearScout

GearScout is a Dalamud plugin for Final Fantasy XIV that extends the game's **Recommended Gear** workflow across all gear you already own.

It can use Allagan Tools inventory snapshots to look across your inventory, Armoury Chest, chocobo saddlebag, retainers, glamour dresser and armoire, then help you build a persistent retrieval/equip checklist for a character or retainer.

> Early beta. GearScout is read-only: it never moves or equips items automatically.
